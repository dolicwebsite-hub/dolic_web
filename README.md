# Dolic_Dev

Project Next.js + Tailwind CSS tổng hợp toàn bộ dữ liệu từ:
- `data/`
- `Dolic - PDF/`
- `Dolic Brand Guideline v1.docx`

## Run

```bash
npm install
npm run dev
```

## Cấu trúc chính

- `content/`: dữ liệu đã trích xuất từ DOCX/XLSX
- `public/assets/brand-pdf/`: PDF logo/icon
- `app/page.tsx`: giao diện hiển thị toàn bộ dữ liệu
